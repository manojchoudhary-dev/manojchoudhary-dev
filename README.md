# Hi, I'm Manoj Choudhary

**Founder & CEO — [SlopeMaps](https://slopemaps.in)** · B.Tech CSE (Core), Semester 1 — IIIT Bhopal

I am building **SlopeMaps**: last-100-metre navigation inside large venues — malls, hospitals, campuses and gated societies. A visitor scans a QR code and gets step-by-step directions from the gate to the exact door. No app to install, no hardware to deploy. A live pilot is running.
